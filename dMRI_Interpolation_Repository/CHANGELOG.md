# Changelog

## Version 1.1.0 — 2026-11-10

- Replaced the isolated GP and CNN patch demonstrations with complete-slice
  reconstruction workflows.
- Added overlapping patch traversal, Hann-weighted overlap-add joining,
  boundary coverage, and exact restoration of observed dMRI samples.
- Added full-slice comparison figures, error maps, numerical result archives,
  a command-line demo, and an automated patch-joining test.

## Version 1.0.0 — 2026-11-10

- Added sample-aligned nearest-neighbor and bilinear interpolation for raw
  dMRI.
- Converted and integrated the earlier patch GP, CNN, DTI, FA, visualization,
  and tractography workflows.
- Added a generalized Wishart process implementation for second-order tensor
  fields.
- Added a canonical decomposition process implementation for tensor orders 2,
  4, and 6.
- Added the anonymized dMRI study, gradient files, and tensor-field datasets.
- Added five Google Colab notebooks and command-line demonstrations.
- Added numerical tests, citation metadata, software and data licenses, and
  reproducibility documentation.
