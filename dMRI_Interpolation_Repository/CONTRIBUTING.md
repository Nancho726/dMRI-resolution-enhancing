# Contributing

Contributions that improve reproducibility, numerical validation,
documentation, or compatibility are welcome.

1. Create a branch from the current main branch.
2. Keep raw-dMRI methods separate from tensor-domain methods.
3. Add or update tests for every numerical change.
4. Run `python run_core_tests.py` before opening a pull request.
5. Describe any change in coefficient ordering, coordinate conventions, random
   seeds, or default hyperparameters.

Do not commit identifiable clinical information. Any additional clinical data
must be fully anonymized and accompanied by appropriate authorization and
licensing information.
